# 💎 AMBERLY – Tienda de Accesorios
## 📖 Descripción
**Amberly** es una página web de tienda online diseñada para la venta de accesorios y joyería.  
Permite visualizar los productos, conocer sus precios y agregarlos a un carrito de compras de forma práctica e intuitiva.

---

## 🛠️ Tecnologías usadas
- **HTML**
- **CSS**  
- **Bootstrap**
- **JavaScript**
---

## 🚀 Instrucciones de instalación o visualización
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador web preferido.
3. Navega por el catálogo de productos y agrega artículos al carrito.

> 💡 No se requiere instalación adicional ni servidor, el proyecto funciona directamente en el navegador.
